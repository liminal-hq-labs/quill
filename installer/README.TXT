QUILL

A word processor for DOS, Windows 3.1 and Windows 95 and later.
Documents are .QLD files. Quill also opens and saves Rich Text
Format (.RTF) and plain text (.TXT).

INSTALLING

  DOS ............. run SETUP from the disk. Quill goes in C:\QUILL;
                    start it with QUILLDOS.
  Windows 3.x ..... run SETUP from the disk in File Manager or
                    Program Manager (File, Run). Quill goes in
                    C:\QUILL and gets its own Program Manager group.
  Windows 95 ...... run SETUP from the disk. Quill goes in
  and later         C:\Program Files\Quill, in the Start menu, and
                    in Add/Remove Programs.

REPAIRING

SETUP has no repair of its own yet. To repair a damaged install,
run SETUP again over the same folder: it overwrites the program
and its files and leaves your settings and documents alone.

REMOVING

  DOS ............. run SETUP /U from the disk.
  Windows 3.x ..... use "Uninstall Quill" in the Quill group, or
                    run UNINST.EXE /U from the Quill folder.
  Windows 95 ...... use Add/Remove Programs in the Control Panel.

Removing Quill deletes only the files SETUP installed. It leaves
QUILL.INI, your dictionary and your documents.

FILE TYPES

Quill registers .QLD files on Windows. Opening .RTF and .TXT files
with Quill is a separate, optional choice in SETUP.

Quill is experimental and may change from one release to the next.
It is a Liminal HQ Labs project.
