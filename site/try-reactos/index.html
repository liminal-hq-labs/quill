Quill on ReactOS

A local experiment. ReactOS runs in v86, an x86 emulator that compiles to WebAssembly. Nothing here is published, and nothing is uploaded.

This browser can't run WebAssembly, which the emulator needs.

Not started. The emulator is about 2 MB and loads when you start it.

Select the screen to give it the keyboard. Click the screen twice to lock the mouse; press Esc to release it.
