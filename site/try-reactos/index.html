Quill on ReactOS

Quill is a small word processor written in Rust, and the same code runs on MS-DOS, Windows 3.1, Windows 9x and Linux. Here it runs on ReactOS, an open-source Windows, inside a PC that is emulated in this tab. Type in the letter, change the fonts and try the menus.

A Liminal HQ Labs experiment, running only on this computer. Nothing is uploaded.

This browser can't run WebAssembly, which the emulator needs.

Not started. The first start downloads about 16 MB, then the desktop is up in a second or two.

Clipboard: off
  • Select the screen to give it the keyboard and the mouse. Press Esc to let the mouse go. In Firefox on Linux the screen follows the mouse without holding it: move off the screen, or click outside it.
  • Full screen gives the biggest picture. Add ?scale=int (whole-number sizes), ?scale=crisp (sharp pixels) or ?scale=smooth (smoothed) to the address to choose how the screen is scaled.
  • The Windows 3.x, slow icon runs inside WineVDM: that is emulation inside emulation, so it takes a few seconds to appear and types more slowly. The 32-bit build is the fast one.
  • Reset loads the saved desktop again. Nothing you type is kept.
  • If you choose Shut Down in ReactOS, the screen dims and the page says so: Turn on brings the saved desktop back. A full boot of the disk, without the saved desktop, is in the builder and diagnostics.

Copy and paste

  • Copy and paste work between this page and ReactOS, for text, formatted text and pictures. Select the screen first (one click on it): sharing starts then, and not before.
  • Copy in ReactOS as you would in Windows (Ctrl+C, or Edit then Copy), and your own clipboard has it, ready to paste anywhere on your computer. A web page may only write your clipboard just after you press a key or click, so a copy you make with the menu or a long while after pressing may show Copy from ReactOS: press it to finish. A large picture, such as a full screen, always takes that button.
  • To paste into ReactOS, press Ctrl+V (Cmd+V on a Mac) while the screen is selected, or press Paste into ReactOS and then paste in ReactOS. A large paste shows its progress and can be cancelled with Esc or Cancel. The page reads your clipboard only when you do one of those, never on its own.
  • Text may be up to 1 MB, formatted text up to 4 MB and a picture up to 4 MB. Rich text reaches your computer as HTML next to the plain text (a web page cannot write RTF).
  • Nothing leaves this tab: the clipboard goes between the page and the emulated PC only, and is forgotten when you stop. Share the clipboard turns it all off (the setting is remembered), and so does ?clipboard=off in the address.
  • If the chip says the guest helper was not found, the saved desktop is an older one without the helper, and everything else works as before.
