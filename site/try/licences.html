Licences and sources

The Try Quill page runs five separate pieces of software. Each keeps its own licence, and the source of each is public.

What is on the page and the disk

PartLicenceSource
Quill (QUILLDOS.EXE, this site) Apache-2.0 OR MIT. QUILLDOS.EXE carries CWSDPMI, below. github.com/liminal-hq-labs/quill
FreeDOS 1.3: the kernel (KERNEL.SYS, build 2043) and FreeCOM (COMMAND.COM) GNU General Public Licence, version 2 or later. Both are exactly as FreeDOS 1.3 ships them. github.com/FDOS/kernel, github.com/FDOS/freecom, and the FreeDOS 1.3 distribution
CuteMouse 2.1 beta 4 (QUILL\CTMOUSE.EXE), the mouse driver, as FreeDOS 1.3's package repository ships it, with one two-byte change that switches off its speed-dependent acceleration GNU General Public Licence, version 2. Nagy Daniel and others. ctmouse.zip (the package holds the source), and scripts/patch-ctmouse.py, which makes the change and says where it is in the source
CWSDPMI, the DPMI host inside QUILLDOS.EXE Redistributable unmodified under the GNU General Public Licence, or without its source if the user is told they may have it, which this says. Charles W. Sandmann. csdpmi7s.zip
js-dos 8.5.3, the player, with its DOSBox build for WebAssembly GNU General Public Licence, version 2. The player's files are served unmodified from this site, with the licence text and a note of where they came from. github.com/caiiiycuk/js-dos, dosbox.com
The page's bridge to the PC (bridge.js, the dos-bridge module), two empty hard disk images (C: and D:) and SYNC.COM on the floppy, a program of 19 bytes Apache-2.0 OR MIT. The images are empty FAT volumes formatted by mtools, a build tool (GNU General Public Licence, version 3) that is not part of the page or the disk; SYNC.COM is written by the build from its bytes, which are listed in scripts/make-bridge-disks.py. site/try, scripts/make-bridge-disks.py
The fonts for the graphics mode (QUILL.FNT) SIL Open Font Licence 1.1. Desk Serif, Sans and Mono, copyright 2026 Liminal HQ, Scott Morris. assets/fonts/desk
The Canadian English dictionary (EN_CA.DIC) Made from SCOWL, which may be used for any purpose when its copyright and permission notices are kept; they are inside the dictionary file. dict/

The disk is a repeatable build, not a download: scripts/build-try.sh in the repository fetches the FreeDOS 1.3 floppy edition from a pinned address, checks it against a pinned SHA-256 sum, takes the kernel, the shell and the boot sector from its boot floppy without changing them, and fetches CuteMouse the same way (changing two bytes of it, with scripts/patch-ctmouse.py, so that the pointer moves the same distance for the same movement at any speed), and adds Quill's files and a short FDCONFIG.SYS and one batch file for each display, then packs the floppy with two empty hard disk images that the page and FreeDOS share (the page puts today's date on one, so Quill's date is not 1998). The GitHub Pages workflow runs it on every publish, so the disk on this site is always built from the source in the repository. Inside the PC, FREEDOS.TXT says the same.
