# The Unicode test document set

Generated by `scripts/gen-unicode-docs.py`; do not edit a file here by hand (two RTF files are hand-written and say so in `manifest.toml`). `python3 -I scripts/gen-unicode-docs.py` rewrites the set and `--check` fails when a file is stale.

Each document `NAME` has four reference files: `NAME.expect` (its code points as the format defines them), `NAME.today` (what today's readers give), `NAME.clusters` (the length of each cluster, a line a paragraph) and `NAME.breaks` (where a line may break). `manifest.toml` lists each document with its source, what it checks, the code points it holds and what each build is expected to show. A document that still differs from its `.expect` names the package that fixes it in `flips`; that package makes `.today` equal `.expect` and removes the line. The design is in [plans/unicode.md](../../../docs/plans/unicode.md) and the decision is CORE-225.
